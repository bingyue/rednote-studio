# 页面与交互

四个一级导航：创作、Skills、发布、账号。暖白工作纸、珊瑚红动作按钮、低饱和绿辅助色。主编辑区强调连续写作，右侧集中放置可预览的 AI 结果和风险复核，避免强迫用户在多个后台跳转。

| 页面 | 关键交互 |
|---|---|
| /create、/create/:id | 账号绑定、草稿搜索、折叠侧栏、标题正文、Markdown 工具、话题、多图、自动保存、版本恢复、AI 撤销 |
| /skills、/skills/:id | 分类卡片、选择目标稿件、上下文/独立模式、输入、执行历史、差异预览、编辑建议与应用 |
| /publishing | 状态筛选、列表/周历、创建任务、选择提醒时间 |
| /publishing/:id | 快照、预检、更新版本、复制下载、官方页面、人工确认链接、取消/失败原因、事件审计 |
| /accounts、/accounts/:id | 账号资料、授权来源、风格样本、环境引用、CLI 操作指引 |
| /assets | 图片上传、尺寸信息、下载；编辑器内可选取 |
| /ideas | 收集灵感，转为绑定账号的草稿 |
| /history | 真实与演示记录区分、CSV 导入、最新快照指标 |
| /settings | 模型状态、编辑字数、风险词库、令牌与扩展说明 |

编辑状态：待保存 → 保存中 → 已保存 / 保存失败。服务端乐观锁冲突保留本地输入；不覆盖较新版本。离开浏览器前提示未保存内容。路由切换遇到待保存内容，先保存并提示再次切换。

AI 修改先显示左右对照，文本建议可以编辑，用户明确采用后保存新版本。保留原稿不会写入，撤销 AI 应用也创建一个新版本。风险改写后自动重新检查，人工忽略必须填写至少四字理由。

封面提供预览、3:4/1:1/9:16、三种布局、主副标题、字号、宋/黑体、三种颜色、背景图裁切位置；超出安全区禁止导出。移动端侧栏折叠为菜单，助手排列在正文下方。
