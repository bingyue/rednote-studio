# 风险提示引擎

规则命中并不等于违法，漏检不等于合法。本产品不输出“必过审”“不被限流”或流量保证。

流程：
1. 获取当前稿件 revision 和工作区启用词库。
2. 检查标题、正文、话题连接文本、封面主/副标题；保存字段、Unicode codepoint 起止位置、命中文本、分类、等级、说明、替换建议、source_type、review_required。
3. 识别简单否定语境并提示人工判断；“第一步/第一次/第一天”等顺序表达不作为排名承诺。此处是本地启发式语境判断，不伪装 LLM。
4. 可选 AI 上下文辅助。真实模型未配置时显示 Mock 语境清单；模型失败保留词库结果并显示失败。全篇语境提示使用 field=context、span=0，不伪造原文定位。
5. 用户可以采用改写（产生新版本并重检），或填写理由保留表达。ReviewDecision 不跨版本继承。

编辑器 Highlight 按 codepoint 切分而非 JavaScript UTF-16 下标，emoji 不会导致偏移。检查既绑定 revision 又绑定词库指纹；修改封面、账号、正文或规则都会要求重新核对。发布预检要求当前有效检查的全部提示都有处理结果。

内置 27 条词汇涵盖绝对化、收益效果、健康主张、教育承诺、站外引流、权利与隐私。它们是维护日期为 2026-10-25 的**演示启发式规则，不是平台官方禁词清单**。具体替换只是建议，有时需要重写整句，不能机械替换后认定无风险。

这些来源用于提示需要核实的类别，不构成逐词违法判定。行业规则、商业合作、医疗/金融/教育等场景应按当前适用官方规则人工复核。设置页可更新每条词、等级、解释、来源及启用状态。未实现 OCR；图片文字检测仅覆盖编辑器已知的封面文字。
