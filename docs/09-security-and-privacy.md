# 安全与隐私

当前定位为单用户本地应用，开发和容器宿主端口默认仅绑定 loopback。服务用固定本地主体，通过 WorkspaceMember 检查所有业务实体工作区；调用者不能提供 user_id 冒充主体。允许来源白名单与 Host 白名单限制浏览器跨来源写入。配置访问令牌后，校验成功会建立 8 小时、HttpOnly、SameSite=Strict 的本地随机会话，供同源图片与下载使用；重启服务使会话失效。多人身份认证、邀请和角色管理未完成，不应直接暴露公网。

写操作由 Pydantic 校验；SQLAlchemy 使用参数化查询。外部模型的输出只允许受限 patch，由人预览；没有执行系统命令、SQL 或发布动作的工具调用。运行错误不回传 Key 或供应商原始响应。模型输入包含当前稿件与账号普通配置；开启 live 前应了解供应商数据政策。

上传白名单与字节上限，Pillow 解码校验后重新编码，随机文件名，移除 metadata，限制像素。路径不由上传文件名决定，文件读取必须先验证 Asset 所属工作区。正式 API 不接受 SVG/HTML。删除带发布记录的稿件被拒绝，以保留审计。

修改草稿以 revision 防止覆盖；应用/恢复都追加快照。发布确认通过状态条件更新和数据库唯一约束防重。生成日志、复核理由、发布事件均保存在本地数据库。

Profile 默认是本机独立目录。CLI 不读取、导出或上传 Cookie，不扫描已有 Chrome 数据。创建需要确认；删除要求双重确认且拒绝符号链接、非托管目录和浏览器锁。它不是反检测浏览器。

当前限制：没有数据库静态加密、自动备份、S3、团队登录。磁盘权限与操作系统账号仍是主要边界。固定本地主体的访问令牌只用于单工作区，不能声称多用户隔离已交付。详见已知限制文档。
