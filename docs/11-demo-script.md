# 10 分钟演示脚本

1. 打开 `/create`。查看 3 个演示账号、草稿列表和清晰的 Mock 标识。新建一篇笔记并选择账号。
2. 点击「选题生成」，输入“轻量工作”，运行并查看 10 条建议。选择一个标题，预览差异后应用。
3. 点击「笔记写作」，输入“轻量工作”，运行；预览标题、正文、话题和封面配置，可编辑建议，再确认应用。
4. 修改一个细节，等待保存。打开版本历史并查看原稿；必要时恢复。AI 应用后可以点击撤销。
5. 在封面设计切换「灵感便签」，调整文字或颜色，导出实际 PNG。尝试更小字号避免文字超出安全区。
6. 回到文案检查内容。可测试“保证有效”，观察上下文与位置；采用改写后重检，或给出明确人工判断理由。最终把内容改成真实、准确的表达。
7. 点击准备发布，逐项查看预检。确认最终稿、账号和素材权利。开始人工发布。
8. 复制标题与正文、下载封面/素材、打开官方页面。**实际演示只到此步骤，无须对外发帖。** 若真实创作者自行完成发布，再回填真实链接确认。
9. 到历史作品查看记录，可下载 CSV 模板并手动导入观察快照。演示已有作品明确显示“演示记录”。
10. 打开 Skills、账号、灵感、素材、设置，展示可调用 Skill、风格样本、Profile CLI 和自定义词库。

自动化 E2E 使用隔离数据库与合成链接完成第 8–9 步记录测试，不能把该测试称为小红书平台发布成功。

离线演示：断网双击 `prototype/index.html`；操作保存在该原型 localStorage。它与正式应用相互独立，始终显示“交互原型 / 演示数据”。
