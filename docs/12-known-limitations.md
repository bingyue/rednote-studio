# 已知限制与下一步

本版本是生产 Demo 级本地工作台，不是已完成公网安全评估的多人 SaaS。

| 范围 | 现状 / 限制 |
|---|---|
| 平台发布 | 人工发布记录流程可运行；没有官方发布 API 权限，不会自动提交或获取成功回执 |
| 浏览器辅助 | MV3 资料导入/复制/导出/打开可运行；无 DOM 自动填写，未在用户真实扩展安装与已登录页面验收 |
| Profile | CLI 可执行、受限参数和路径已测；未创建或打开用户真实账号环境，需本人确认和手动登录 |
| 真实模型 | 有兼容适配器、校验、超时、重试与审计；无凭据时只测试 Mock 和模拟供应商响应，不声称真实供应商验证 |
| 合规 | 启发式规则与人工复核；不是法律意见或平台审核保证。无 OCR；只检查已知文本 |
| 账号授权 | 用户声明授权，不连接平台验证身份；登录状态为未检测 |
| 多人 | 用户/工作区/成员实体和边界存在；邀请、独立账号认证、评论共享、最多 5 人管理界面未实现 |
| 存储 | SQLite 和本地文件完成；PostgreSQL 可配置但未集成实测；S3 未实现 |
| 自动提醒 | 页面打开时显示到期提示；没有离线推送、邮件、系统通知或后台自动发布 |
| 数据分析 | CSV 人工快照、按最新快照汇总；无平台实时同步、外部笔记抓取或效果归因 |
| 富文本 | Markdown 输入与安全预览，非所见即所得 TipTap；PNG 使用本机字体，平台不同可能有字形差异 |
| 图片 | 前端 Canvas 配置、位置裁切和安全区提示；JPEG 重新编码不保留透明通道；未实现自由手绘裁切框 |
| 本地密钥 | 使用后端环境变量，不在数据库/前端存 Key；没有加密秘密管理 UI |
| 运行历史 | Skill 最近 50 条，暂无分页搜索与成本价格表；没有已知单价时不估算费用 |

正式化优先次序：账号登录与会话策略 → 多人授权测试 → PostgreSQL/S3 验收 → 官方接口授权核实 → 有明确权限的浏览器填写实验 → 通知机制。每一步都保留人工控制，不增加自动群控或平台绕过功能。
